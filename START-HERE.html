◎ RoleRadar

Your job search, in one place.

A private local dashboard for CV matching, applications and job-specific resumes.

Start on Windows

1

Extract the ZIP

Right-click the downloaded ZIP and choose Extract All. Keep the full RoleRadar folder together. Don’t run the app from inside the ZIP.

2

Install Python, if needed

Use Python 3.10 or newer from python.org. Select Add Python to PATH when installing.

No paid software or extra packages are required for the core dashboard.

3

Double-click Start-RoleRadar.bat

Your browser opens the dashboard. Keep the launcher window open while you use it. If the browser doesn’t open, visit http://127.0.0.1:8765 after starting the launcher.

4

Add your CV

Open My CV. Import DOCX or TXT, or paste your CV. Check the extracted text, enter total years of experience, then click Save CV & refresh matches.

No app can reliably cover every vacancy on the internet. This app does not scrape restricted sites or apply on your behalf.

Your daily workflow

  1. Search by role, country, city and specialism.
  2. Review each 1–100 match score, supporting CV evidence and missing requirements.
  3. Open the apply link and submit yourself. Then mark the job Applied.
  4. Add recruiter calls, interviews and outcomes under Updates. Set a follow-up date if useful.
  5. Use Resume studio to tailor an editable draft for that job and download Word, text or print to PDF.

A score is text similarity—not an ATS result, verified skill assessment or hiring probability. Check eligibility and requirements yourself.

Want AI resume rewriting?

The basic Tailor from CV button works immediately: it highlights genuine matched skills and reorders bullet groups within each role. It is not generative AI.

For actual AI rewriting, install Ollama, then download a local model. For example, run:

ollama pull llama3.2

In the dashboard, open Connections & data → Find models → select your downloaded model → Use selected model. Then choose Rewrite with local AI in Resume studio.

The model may require several GB of disk space; speed depends on your computer. Cloud models are excluded. Check every draft for invented or altered facts before sending it.

Keep your data safe

Your CV, jobs and notes are stored in the app’s data folder. Don’t delete it when updating or moving the app.

Use Connections & data → Export backup regularly. Backups contain personal information and are not encrypted. Import adds new jobs without replacing existing records.

API keys entered in the dashboard last for the current app session. You will need to reconnect after restarting. No API keys are included in backups.

PDFs, Mac and Linux

PDF import: run Install-PDF-Support.bat once for text-based PDFs. It asks before downloading the optional package. Scanned PDFs need OCR elsewhere. DOCX and pasted text work without this step.

Mac / Linux: open a terminal in this folder and run python3 app.py. Python 3.10+ is required.
